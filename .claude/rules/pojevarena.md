# PoJevArena

- **PoJevArena** (2026-09-25; `Features/PoJevArena`, `Games/PoJevArena`, `js/pojevarena/`, spec in `SPEC.md`). A 10v10 creature battle where every tactical decision comes from TypeSafe's **Jev** (OpenRouter, `POST {Endpoint}systemone`, model pinned to `typesafe/jev-1.13`). Jev is **required, with no decision fallback anywhere real**: no key → `status.configured=false` and Deploy is disabled; a failed or late call makes the unit hold its last intent indefinitely (the user's call). `StubJevClient` exists for the test hosts only — `PoMiniGames:Jev:UseStub` is honoured solely under the `Test` environment (stricter than `AiMockFallback`, which also allows Development) and is the one `TestBudgetGuard` line. The key is Key Vault `PoMiniGames--Jev--ApiKey` (conditional secret back in `infra/kv-secrets.bicep`; the vault secret itself survived the 2026-09-23 "drop the jev leftovers" commit, so dev and prod already have one). **The server writes every word Jev sees**: the browser sends only numbers and catalog ids, the unit's creature (names included) is resolved from the server-held match roster, and `JevPromptBuilder` builds the state and question set — so the proxy can't be used as a free Jev pass-through. Its output is pinned by Verify snapshots (`*.verified.txt`); a wording change is a behaviour change for the model and must show up as a reviewed diff. The daily cap (20k calls/identity) is a second `AiTokenBudget` counting calls over table `PoJevArenaCallLedger`, flushed by a second `AiTokenBudgetFlushService` registered via `AddSingleton<IHostedService>` — `AddHostedService<T>` is a TryAddEnumerable and silently drops a second instance of the same type. The ability registry (`PoJevArenaCatalog.Abilities` in `Shared/Games/PoJevArenaShared.cs`) is the extension point: adding an ability is that row + one handler in `abilities.js` + one visual in `fx.js`, and nothing else names abilities. Every creature melees; an 80-point build budget bounds stats + abilities; creatures fight on **battle HP = designed HP / 5** (`PoJevArenaRules.BattleHp`, mirrored by `sim.js` `battleHp`; the user's call 2026-09-30). Designed HP (50–500) is still what the budget prices and the library stores, but everything a player or Jev reads — factory slider, cards, inspectors, the prompt's `HP: x/y` — is battle HP, and the prompt builder validates the reported HP against it, so the two rules must change together. `DAMAGE_SCALE` stays 0.5; scripted headless matches run 12–21 s and a real-Jev match ~50 s (was ~2:40). Engine: `sim.js` is pure and node-runnable, `scheduler.js` runs on *sim* time (hidden tab = no calls), `blackbox.js` records every frame for the scrubber, `debrief.js` turns its decision log into the end-of-match "what each team was thinking" summary (numbers only; `JevDebrief.razor` owns the wording, and a debrief runner-up is the best option Jev did *not* pick, because its pick is not always the argmax), and the page's only road to the server is `[JSInvokable] DecideAsync` (so every call rides the antiforgery/credentials `HttpClient`). Two test-harness facts found building it: the Integration factory's storage override lands after the host binds `TableServiceClient`, so Integration tests write to the developer's **local Azurite** (the library test deletes what it creates for that reason); and the E2E-API fixture registers no header FakeAuth at startup, so signed-in E2E-API rows sign in through `/auth/login/fake` instead. Under `?autoGuest=1` the play-session mint 403s once on every game page (token predates the guest identity) — known, tolerated, not the page's. **2026-09-30 pass (SPEC §15):** three seeded hazard maps (`sim.js` `ARENAS`: pillars, brush, tar) and a fourth base option `take_cover`, so every `tactical_action` snapshot carries it and the state has `coverDistanceM`/`inBrush`/`inTar` (validated server-side; -1 means no pillars). Creature Elo + careers ride the existing result report as increments; the result body is still the client's word, only clamped. Sound (`audio.js`) rides `PoAudioBus`'s sfx bus and music is `PoMusicDirector.tension` — no own AudioContext, no own mute. `postfx.js` is an optional WebGL2 grade over the 2D canvas: the 2D canvas stays the input and pointer target (`is-composited` makes it transparent, never hidden), and it must stay first in DOM so glassFx's largest-canvas pick samples it, not the GL canvas. The whistle now plays a kill cam + ceremony (~7 s, skippable, skipped under reduced motion) *before* `OnMatchEnded`, so anything waiting on the result waits for that too. The Black Box floor keeps its stains across scrubs (it is the whole match's record). Blazor renders a `bool` attribute as present/absent, so `aria-pressed` goes through the page's `Pressed()` helper. **Locomotion is force-based** (2026-09-30, `sim.js` `integrate`): no per-tick damping and no velocity is ever set directly. Legs push toward the wanted velocity, capped by grip (μ·m·g, g = 9.81, masses 24–120 kg) and by leg power (P/v); unfooted bodies (reeling, shelled) skid on kinetic friction; air drag and tar resist. Leg work drains a critical-power/W′ energy reserve (cruise ≈ sustainable, sprint and bursts spend it, empty = 40% power and no sprint), reported to Jev as `Stamina` (-1 = not reported, so older snapshots are unchanged) and drawn under the HP bar. Lunges and dodges are explosive pushes, not velocity kicks. Boulders fly a real ballistic arc (`arcHeight`): they sail over bodies mid-flight and land where aimed. Every non-DoT blow shoves its victim (impulse ÷ effective mass, closing speed cancelled, a stagger that suppresses steering and new swings); colliders are 1.15× the drawn body radius and contacts relax over 3 passes. The live battle is full screen: the team columns and HUD pill only show while Tab is held (engine `OnStats`) or the Stats button is on. The debrief ends with one story per unit (`debrief.js` `story`, worded in `UnitStories.razor`). **Combat-style walls (2026-10-01).** Every arena also gets a wall layout from the match seed (`sim.js` `mazeFor`, called by `arenaFor(seed)`, on its own PRNG stream so spawn jitter is unchanged; render.js builds the same arena from the seed, so a Black Box scrub shows the same map): up to three chunky pieces in one quarter copied into all four, so it is mirror-symmetric both ways, with a 2 m lane kept between pieces, the edge, tar and the spawns. Bodies collide with walls like pillars, walls stop globs, mend bolts and boulders, ranged abilities ask `kit.sight` first, and `aroundWalls` routes a `kit.towards` command round corners on a visibility graph cached on the arena (pure geometry, no RNG). Cover is the nearest pillar OR wall through the existing `coverDistanceM`/`take_cover`; no prompt, state field or C# changed, so the prompt still says "pillar" where the cover is usually a wall (changing that wording means re-approving the Verify snapshots). Walls win the space: a pillar with less than a lane to a block sits the match out, which is most of them. A knockout holds the frame for 90 ms (2026-10-01): `onKnockout` calls `PoImpact.hitstop` and the live loop scales the sim time it feeds by `PoImpact.getTimeScale()`, the same lever as the late-knockout slow motion, so the scheduler (sim time) makes no extra Jev calls. Known: in 4 of 300 headless matches a unit stalled 5 s queued behind allies plugging a lane or wading the tar pit; fixing that is crowd-aware flanking, not built.
