Multi-Agent Performance Comparison

How the computer-controlled characters in PoMiniGames compare on skill, smoothness and running cost. Snapshot 2026-10-03.

Tier 1 · Quick look
No agent here was trained, and none has been benchmarked. There are no learning curves and no profiler runs in the repo. Every number on this page is either a tuning value read from the source code, or a measurement a developer wrote in a code comment. Each chart says which. Hover a mark for its exact value.
  • Skill is set by tables. PoBrawl's top rung reacts about six times faster than its bottom rung.
  • Smoothest movers: PoCabinet racers and PoBrawl boxers. Twitchiest: PoRacer bots and PoVoxelStrike monsters.
  • Heaviest crowd: PoEcosystem, up to 400 creatures. Only agents that cost money per decision: the hosted models.

Tier 3 · Setup guide

How to get real benchmark numbers

To measureHow
Frame cost of an agent crowdOpen the game in demo mode with browser dev tools, Performance tab, record 10 s. Compare with the crowd cap halved.
Frames per secondThe client has an FpsCounter component; several games also accept a ?debug flag.
Server tick cost (PoRacer, PoCabinet online)Time the sim step in the race service and log it; both run on timers in the API.
Win ratesSee "Getting real numbers" in training_metrics_guide.md.
Hosted-model spendGET /api/health/ai reports usage; the daily ledgers are the AiTokenLedger and PoJevArenaCallLedger tables.

Run headless measurements on mains power with one browser at a time. Battery saving and parallel browsers both produce false slow readings.
