Creature & Behavior Dashboard

Every computer-controlled character in PoMiniGames, as of 2026-10-03. Switch views with the toggle.

Nothing here was trained. These agents are hand-written rules or hosted models, so there are no training success rates to show. Ability levels are a design rating read from the code and tuning tables, not a measurement. Where a real measurement exists it is quoted and labelled.

Abilities grid

Each row is an agent. Each column is a behavior. More filled blocks means the behavior is more developed.

Strong Capable Basic None n/a = the game has no such behavior

Scorecards

The bar is the share of this agent's applicable behaviors that are developed (average level out of Strong). Badges are abilities that exist in the code today.

Hosted-model agents

These write text or pick tactics. They have no body and no arena, so they sit outside the grid.

Inspector-level settings

Think rate, senses, controls, body, joint limits and source paths for each agent. Paths are relative to src/PoMiniGames.Client (prefix C/) or src/PoMiniGames.API (prefix A/).
